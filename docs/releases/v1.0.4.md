# v1.0.4

- 发布版本：`v1.0.4`
- 上一个版本：`v1.0.3`
- 提交说明：fix: 修复 WorkBuddy 市场 401/COS 降级/技能安装/连接器视图，并完成豆包风上浮面板真机打磨
- 测试：442 条通过（45 个测试文件）

## 本次新增与修复

- 修复 WorkBuddy 多区域账号令牌混用导致市场 401：按区域优先选号并在 401/403 时自动换号重试，门户不可用时正确回落 COS 公开快照并透传提示
- 修复新会话未自动激活已启用来源（含并发 /state 与 /providers 的 SessionManager.readActive 竞态），退出专家保留本会话已选来源
- 修复前端技能安装透传真实 skill_id 与服务端按 slug 兜底解析，支持一键落盘至项目 .dsh/skills/<slug>/
- 优化连接器列表：合并真实有工具的已装插件与本地目录连接器，透传真实连接状态、工具数与目录只读标记
- 打磨豆包风上浮面板与完整工作台：单行胶囊、Portal 毛玻璃、真实专家分类、全库搜索与翻页、快捷退出专家与行内高亮、Toast 自动消退、修复设置页空 defaultProvider 误报红字
