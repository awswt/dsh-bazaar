# v1.0.3

- 发布版本：`v1.0.3`
- 上一个版本：`v1.0.2`
- 提交说明：feat: 按 design 原型 v2.1 重写前端两屏与上浮面板
- 测试：434 条通过（45 个测试文件）

## 本次新增与修复

- 设置页 Provider 栏内建全局启用/禁用开关，禁用后该 Provider 的专家/技能/连接器不在会话面板与完整面板显示；全部禁用时给空态并引导回设置页
- 输入栏入口收敛为专家/技能/连接器三个胶囊，新增豆包风格上浮面板（来源胶囊+分类标签+常用/推荐分区+底置搜索）与常驻完整面板入口
- 工作台按域分页签、分类本地筛、单库重试、跨库同名冲突详情、memoryMarket 未声明态如实表达、连接器目录只读复制片段
