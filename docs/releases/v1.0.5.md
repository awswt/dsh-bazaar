# v1.0.5

- 发布版本：`v1.0.5`
- 上一个版本：`v1.0.4`
- 提交说明：feat(auth): 彻底剥离外部插件依赖，升级为 Provider 独立单凭证一键认证与会话面板就地登录
- 测试：431 条通过（45 个测试文件）

## 本次新增与修复

- 架构剥离：彻底移除对 ~/.dsh/workbuddy-vault 与 dsh-connect-workbuddy 的探测、读取与导入逻辑，市场访问凭证 100% 独立存储在 ~/.dsh/bazaar/providers/<id>/accounts/
- 单凭证极简模型：每个 Provider 仅维护唯一一份市场访问凭证，新授权落盘自动清理覆盖旧凭证，支持自动续期、手动刷新与安全退出
- 零表单一键网页认证：移除登录区域必选下拉框与多账号列表，点击「立即登录认证」自动拉起浏览器完成网页授权
- 全界面状态严格一致与就地认证：未认证或凭证失效时绝不静默回落公开快照混淆状态，设置页、会话上浮面板与完整工作台统一展示中文引导并支持就地一键完成认证后自动刷新列表
