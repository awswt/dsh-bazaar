# dsh-bazaar UI 重设计原型说明

本目录存放 `dsh-bazaar` 能力集市面板的全新交互原型（参考「豆包工作」卡片流，并完全跟随 DSH 宿主浅色/深色基础配置）。

## 文件说明

- [index.html](file:///e:/DSH/workspace/dsh-bazaar/design/index.html)：纯本地可交互高保真原型（无外部 CDN 依赖，直接用浏览器打开即可体验）。

## 核心改动要点

1. **输入栏入口收敛（解决折行与英文混排问题）**
   - 原版：`[ expert | skill | connector | provider ]` + 折行两排的 `[ 完整面板 ]`
   - 新版：输入栏仅保留 **`专家`、`技能`、`连接器`** 3 个单行不折行独立胶囊（`white-space: nowrap`）；移除 `provider` 入口；将「完整面板」收纳到上浮面板底置搜索栏右侧及列表末端的「查看全部与多来源对比 ›」。

2. **豆包工作风格上浮面板**
   - 紧贴输入栏上方浮起，激活时统一外框为强调描边。
   - **顶部**：常驻轻量「来源」过滤胶囊（仅显示在设置页中启用的 Provider）+ 领域分类标签。
   - **中部**：直接呈现「常用」与「推荐/全部」分区，单行高扫描效率排版（图标 + 名称 + 一行浅灰简介 + 右侧状态标签/轻量操作），末尾提供「查看全部与多来源对比 ›」。
   - **底部**：紧邻底部工具栏的底置 `搜索...` 输入框 + `完整面板` 切换按钮。

3. **设置页（屏 A）改为「Provider 栏」与启用/禁用联动**
   - 不再使用「WorkBuddy 专家库」等字样，统一改为 **`Provider 栏`**，每个 Tab 直接对应一个 Provider（如 `WorkBuddy`、`Demo Provider`）。
   - 每个 Provider 页签内置全局 **启用 / 禁用开关**：禁用后该 Provider 的专家、技能与连接器**不在会话面板（屏 B）及完整面板中显示**；如果所有 Provider 都被禁用，会话面板会给出引导前往设置页启用的空态入口。
   - 保留账号与登录（区域必选/扫码/只读）、宿主凭据、本地缓存、连接器授权与版本更新。

4. **不设独立配色页，完全跟随 DSH 宿主主题**
   - 插件内不提供单独的主题/配色设置页面，样式表严格消费 DSH 宿主的 `--dsw-alias-*` 令牌与 `body[data-ds-dark-theme]` 翻转。
   - 所有文本、次要说明与状态徽标均采用 `color-mix(in srgb, ..., var(--bz-fg / --bz-bg))` 现算，确保在 DSH 基础配色、浅色、深色模式下均清晰可读。
